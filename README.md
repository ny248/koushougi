# 広将棋 GUI 対戦プロジェクト

広将棋（Koushougi）を人間同士が GUI で対戦できるようにすることを目的としたプロジェクトです。

## 概要

- 2 人対戦の広将棋を PC 上で遊べる GUI を提供します
- 対局の操作性・視認性を重視します

## 予定機能

- 盤面の表示
- 駒の選択／移動
- 成り／成らずの選択
- 取った駒の管理
- 手番表示・対局ログ表示

## 開発方針

- まずは「人間同士のローカル対戦」を最優先で実装します
- ルールや UI は、段階的に拡張します

## 使い方

準備中です。

## 開発環境

- Python を使用します。

## ディレクトリ構成

（案）

```
.
├── README.md
├── GAMERULE.md
├── .codex/
│   └── AGENTS.md
├── docs/
│   └── notes/
├── src/
│   ├── app/
│   ├── domain/
│   ├── rules/
│   ├── ui/
│   └── utils/
├── assets/
│   ├── board/
│   ├── pieces/
│   └── sounds/
├── tests/
│   ├── unit/
│   └── integration/

```

- `docs/`: 仕様メモ、設計メモ、参考資料の整理
- `src/app/`: 起動・画面遷移・アプリ全体の制御
- `src/domain/`: 盤面・駒・手番などの中核ロジック
- `src/rules/`: ルール判定や合法手生成
- `src/ui/`: GUI 表示と操作入力
- `src/utils/`: 共通ユーティリティ
- `assets/`: 盤面や駒の画像、効果音
- `tests/`: 単体・結合テスト
- `scripts/`: 開発用の補助スクリプト
