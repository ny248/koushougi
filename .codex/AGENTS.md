# AGENTS.md

このプロジェクトでの作業方針と注意事項をまとめる。

## 基本方針
- 目的: 広将棋を人間同士が GUI で対戦できるようにする
- 優先順位: まずローカルでの対人対戦を最優先に実装する
- 言語: Python を使用する

## 進め方
- ルール調査や資料収集は、必要最小限のアクセスで行う
- Web 調査が必要な場合は、事前に許可を得る
- 取得したデータはローカルに保存し、そこから解析・整理する
- 同じページへの繰り返しアクセスを避ける

## 作成物の扱い
- ドキュメントは過不足なく簡潔にまとめる
- ルールは詳細に記載し、出典と参照日を明記する
- 途中生成ファイルは必要に応じて整理・削除する

## 対話と姿勢
- 冗長な手順や無駄な作業を避ける
- 進め方の変更や判断に迷いがあれば、短く確認する
- 指摘された点は即座に改善し、方針として明文化する
