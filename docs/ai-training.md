# 広将棋AIの学習記録

## 現在のモデル

第2世代を採用した。第1世代との再検証では39勝1敗、20組中19組で勝ち越し、40局すべてで勝敗がついた。採用条件は20組中15組以上の勝ち越しと、40局中30局以上の勝敗確定。対局画面の探索AIとの比較は別途行う。

## 第3世代の採用判定

第3世代は第2世代同士の自己対戦20局から7,810局面を得て学習した。第2世代との比較は25勝15敗で、20組中9組で勝ち越し、4組で負け越し、7組で同数だった。40局すべてで勝敗がついた。勝ち越し組数が採用条件の15組に届かなかったため、比較相手は第2世代を継続する。

## 第4世代の採用判定

第2世代同士の自己対戦60局すべてで勝敗がつき、25,395局面を保存した。第4世代は第2世代に4勝36敗で、組ごとの結果は0勝ち越し、16負け越し、4同数だった。騎総と仏狼機の修正後のエンジンを生成・対戦に使用した。

第2世代の重み80%と第4世代の重み20%を混ぜた候補は、別の乱数による40局で20勝20敗だった。組ごとの結果は6勝ち越し、6負け越し、8同数。両候補とも採用条件に届かなかったため、第2世代を継続する。

実行方法は [自己対戦と学習](rules-implementation.md#自己対戦と学習) を参照。

## 世代を進める手順

1. 採用したモデルで自己対戦し、勝敗がついた対局を保存する。
2. 対局単位で学習用と検証用に分けて、次のモデルを学習する。
3. 学習と別の乱数で現行モデルと対戦し、先後の組ごとに採用条件を判定する。
4. 採用後は新モデルを次の自己対戦に使う。画面に組み込む前に、探索AIとの勝敗と思考時間も測る。

実験ごとに、変更した設定、元モデル、対局数、乱数、手数上限、勝敗がついた局数、学習局面数、モデルの保存先、比較結果、採否を記録する。再現に使うコードのコミットがある場合は、そのコミットIDも残す。
