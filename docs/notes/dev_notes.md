## 2024-12-30: piece_loader.py について

- YAMLの仕様が変更される可能性がある（実際に`slide`→`range`形式に変更された）
- 必要なデータ構造が実装時に明確になる前に設計してしまった

**対応:**
- 現状のまま進め、`movement.py`実装時に必要に応じて調整する
- 大きな変更が必要になった場合は作り直す

**教訓:**
- 実際に使う段階になってからユーティリティを作る方が良い
- 先に作る場合は最小限のインターフェースにとどめる
